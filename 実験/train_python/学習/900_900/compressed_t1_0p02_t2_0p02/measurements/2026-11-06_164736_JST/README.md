# 900_900・閾値0.02：メモリ不足で測定を停止

停止した形式：COO。コンパイル時にメモリ容量超過エラーが発生した。

| 項目 | 値 |
|---|---:|
| 使用可能なSRAM | 32,768 B |
| コンパイル時の静的RAM | ビルドログを参照 B |
| predictのスタックフレーム | ビルドログを参照 B |

中間配列は900×2×sizeof(float)＝7,200 B。コンパイル成功だけでは実行可能と判断せず、静的RAMとpredictのスタックフレームだけでSRAMを超える場合もメモリ容量不足として停止した。これは実機をクラッシュさせて確認した結果ではなく、ビルド結果から確定できる容量超過である。

COOの実機への書き込み・推論・PPM取得は未実施。以降の測定も行っていない。Flash配置への変更、閾値の変更、再学習による回避は行わない。
