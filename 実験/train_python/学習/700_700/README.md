# 700_700・閾値0.02

`train_700_700.py` はノートブックを実行して学習記録・非圧縮重み・model_state.ptを保存する。再実行は重みを上書きするため、比較中は保存済み重みから圧縮する。

両層の絶対値0.02未満を0にし、同じ行列からCOO・CSRを生成した。モデルの状態とヘッダーのfloat32値、PCで12入力の出力一致を確認。詳細は `compressed_t1_0p02_t2_0p02/validation_report.json`。この検証はPC上のもので、実機の記録は測定後に別フォルダへ保存する。
