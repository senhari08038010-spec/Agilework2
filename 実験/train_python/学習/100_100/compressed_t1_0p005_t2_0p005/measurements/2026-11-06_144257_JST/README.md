# 100_100・COO／CSR 実機測定結果

2026年11月6日（日本時間）、接続中のArduino UNO R4 WiFiへCOO版、CSR版の順に書き込み、各形式で `i` による条件確認と `r` による測定を行った。両方で `MEASUREMENT_COMPLETE` を確認した。

## 共通条件

- 構成：3 → 100 → 100 → 3。第1・第2層の閾値はともに0.005。
- 元重みSHA-256：`0e4f6f3cd21232c814ee1d9aacd28083442a641be7af672db607873cfe9becc9`。
- 固定評価入力：既存の `evaluation_data.h` の9画素。両形式の入力・計測処理は同一。
- 評価入力元SHA-256：`aef4bbf02c893cd55ca2faee519486b27311c804276259ba551d7c5a0714b562`。
- 第1層の非ゼロ重み44個、第2層118個。第3層とバイアスは非圧縮。
- 非圧縮パラメータ容量：43,212 B。
- Arduino core：`arduino:renesas_uno` 1.5.1、FQBN：`arduino:renesas_uno:unor4wifi`。
- 予備100回の後、1,000回を5セット測定。センサー読み取り・LED操作は行わず、固定入力による推論を測定した。

## 結果

| 項目 | COO | CSR |
|---|---:|---:|
| パラメータ保存容量 | 2,984 B | 3,024 B |
| 圧縮率（圧縮後÷非圧縮×100） | 6.905489% | 6.998056% |
| 容量削減率 | 93.094511% | 93.001944% |
| 平均推論時間（1回、共通の集計処理を含む） | 206.5386 µs | 217.7220 µs |
| MSE（RGB 0～255） | 91.77777778 | 91.77777778 |
| ビルド時のフラッシュ使用量 | 58,672 B | 58,748 B |
| ビルド時の静的RAM使用量 | 9,756 B | 9,800 B |

パラメータ保存容量は重み・索引・バイアスのsizeof合計。フラッシュと静的RAMは今回のコンパイル出力値で、実行中のピークRAM使用量ではない。

COO・CSRの出力PPMは27成分すべて一致した。MSEは `実験/MSE測定/reference_3x3.ppm` を基準とし、RGB各成分の二乗誤差の合計を27で割った。既存の `mse_calculator.html` と同じ計算で、表示を小数2桁にすると91.78。

## 保存ファイル

- 各形式の `serial_info.txt`：書き込み後の `i` 応答。
- 各形式の `serial_measurement.txt`：`r` の生ログ（5セットの時間、容量、PPM、完了通知）。
- `coo/coo_100_t0p005.ppm`、`csr/csr_100_t0p005.ppm`：今回取得した実機出力。
- 各形式の `measurement.json`：条件、ハッシュ、各セットの時間、MSE、ビルド結果。
- 各形式の `arduino_build.txt`：今回のコンパイル出力の容量行。
- `results.csv`、`results.json`：両形式の比較用データ。

以前の `coo/100_100_coo.ppm` と `csr/100_100_csr.ppm` は上書きしていない。今回の出力と既存COO画像には27成分中25成分の差がある。既存CSR画像とは全成分一致する。過去画像の取得条件は今回のログからは特定できないため、今回の比較には同条件で新たに取得した2枚を使う。

測定前の状態はGitコミット `aec70064476bab7db4dd9670bac9eb0a763cc22e` に保存済み。終了時の実機にはCSR 100_100・閾値0.005が書き込まれている。
