# 100_100モデルの学習と測定準備

構成は3 → 100 → 100 → 3。既存の`../../train_L1_normalization.ipynb`と同じ33画素、Adam（学習率0.01）、50,000回、L1係数0.000001を使って新規に学習した。ノートブック自体は変更していない。今回はCPU・float32で乱数シード42を指定し、条件・ライブラリの版・入力ファイルのSHA-256を記録した。過去モデルの未記録の乱数初期値を再現したものではない。

| 保存物 | 内容 |
|---|---|
| `model_parameters.h` | 全6配列を持つ元の非圧縮重み。10,803要素・43,212 B |
| `model_state.pt` | 学習後のPyTorch state_dict |
| `train_100_100.py` | 今回実行した学習スクリプト |

| `compressed_t1_0p005_t2_0p005/` | 同じ元モデルから生成した閾値0.005のCOO・CSR |

元モデルのSHA-256：`1652d72a554967bfbdbdc0cf42f8e504ac472ab81aed64448048eb453df0b5dd`。
学習33画素の最終MSEは0.000031960215（0～1の正規化値）。固定9画素の実機MSEとは別の値である。

## 閾値の比較

今後0.01、0.02、0.03へ進むときも、この`model_parameters.h`を元に圧縮する。学習をやり直さず、同じ枝刈り後のモデルを両形式で使用する。

例：`python3 実験/train_python/compress_weights.py 実験/train_python/学習/100_100/model_parameters.h --threshold 0.01`（リポジトリのルートで実行）。出力先が存在する場合は上書きしない。

0.005のCOOは2924 B（6.766639%）、CSRは2974 B（6.882347%）。圧縮率は圧縮後÷非圧縮×100。現在の測定用ヘッダーにはこの条件を配置した。実機測定は未実施。操作・保存先は`実験/測定条件.md`を参照する。

## 学習を再現する場合

`requirements.txt`の依存ライブラリを用意し、`train_100_100.py`を実行する。作成済みの元モデルの上書きを避けるため、成果物があるフォルダでは実行を拒否する。別のモデルを学習する場合は別の条件フォルダへ保存し、今回の元モデルを保持する。同じシードでもライブラリや実行環境が異なる場合は完全に同じ重みになるとは限らない。
