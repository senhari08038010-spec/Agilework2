# 100_100・閾値0.005の準備

既存の `train_python/train_L1_normalization.ipynb` を複製し、`train_L1_normalization_100_100.ipynb` の3箇所を `Linear(3,100)`、`Linear(100,100)`、`Linear(100,3)` に変更した。データの相対参照は保存場所に合わせ、PPMの基準ディレクトリを `../..`、正解画像を `../../img/` とした。学習処理は既存コードを使い、再現のためシード0・CPU1スレッド・決定的アルゴリズムを設定した。

- 学習入力：新しい3×3の9画素と従来6×6の上4行24画素、計33画素。元データは変更していない。
- 正解：従来と同じ2つの色見本を3×3・6×4へ最近傍リサイズ。
- Adam、学習率0.01、50,000回、重みのL1係数0.000001。
- 学習済みモデル：`model_state.pt`。非圧縮重み：`model_parameters.h`。
- 学習条件・環境・入力ハッシュ：`training_report.json`。入力・正解の実値：`training_data.json`。
- 学習済みノートブック内の出力と `training_log.txt` に実行結果を保存。
- このフォルダを作業ディレクトリにしてノートブックを実行する。再実行するとこのフォルダの重みを上書きするので、閾値比較中は再学習せず、同じ保存済み重みを使う。

## 圧縮

第1・第2層の重みについて絶対値0.005未満を0とし、同じ結果からCOO・CSRを生成した。第3層と全バイアスはそのまま。生成物は `compressed_t1_0p005_t2_0p005/` にある。PC上で復元一致と通常配列による枝刈り後モデルとの推論一致を確認した。

## 測定用プログラム

既存の70用 `scanner_coo`・`scanner_csr` を複製し、実験フォルダ直下に `scanner_coo_100`・`scanner_csr_100` として用意した。Arduinoの規則に合わせスケッチ名もフォルダ名へ合わせた。変更したのはフォルダ・スケッチの名前と100用の重みヘッダーで、推論・計時のプログラムと固定評価入力は70用と同じである。次元数はヘッダーから自動設定される。

測定手順と確認値は `実験/測定条件_100_100_t0p005.md` を参照。実機書き込み・測定は未実施。PCの出力を実機測定済みPPMとしては保存しない。
